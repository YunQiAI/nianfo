# 木鱼音效使用说明

## 音效系统说明

应用现在支持三种木鱼音效模式：

### 1. 外部音效文件 (最佳音质)
- 将您喜欢的木鱼音效文件命名为 `wooden-fish.mp3` 并放在项目根目录
- 支持 MP3、WAV 等常见音频格式
- 应用会自动检测并优先使用外部音效文件

### 2. 内置生成音效 (默认)
- 使用 Web Audio API 动态生成的木鱼音效
- 480Hz 基础频率，带有丰富的谐波
- 模拟真实木鱼的快速攻击和自然衰减

### 3. 备用合成音效
- 当以上两种方法都不可用时的后备方案
- 使用锯齿波和滤波器模拟木质敲击声

## 如何获取更好的音效

### 推荐的免费音效资源：
1. **爱给网** (aigei.com) - 搜索"木鱼声"
2. **Pixabay** - 搜索"wooden fish" 或 "temple block"
3. **Freesound.org** - 搜索 "mokugyo" 或 "wooden block"

### 音效文件要求：
- 格式：MP3、WAV、OGG 等
- 时长：0.2-1.0 秒为佳
- 音质：44.1kHz 采样率，立体声或单声道均可
- 文件大小：建议小于 100KB

### 使用自定义音效：
1. 下载您喜欢的木鱼音效文件
2. 重命名为 `wooden-fish.mp3`
3. 放在项目根目录（与 index.html 同级）
4. 刷新页面即可使用

## 音效特征

### 真实木鱼的声音特点：
- **基础频率**：通常在 300-600Hz 之间
- **音色**：温暖、有共鸣的木质音色
- **包络**：快速攻击（0-10ms），中等衰减（100-500ms）
- **谐波**：丰富的偶次谐波
- **质感**：略带木质敲击的噪声成分

### 内置音效的设计：
- 基础频率：480Hz
- 谐波：960Hz、1440Hz、1920Hz
- 攻击时间：5ms
- 衰减时间：约 400ms
- 添加了轻微的随机噪声模拟木质质感

## 技术实现

应用使用 Web Audio API 的以下特性：
- `AudioBuffer` 用于播放音频文件
- `BufferSource` 用于音频回放
- `GainNode` 用于音量控制
- `BiquadFilter` 用于音色调整（合成音效）

## 自定义和调试

如果您想调整音效参数，可以：
1. 修改 `wooden-fish-data.js` 中的参数
2. 在浏览器控制台查看音效加载状态
3. 使用 `test-sound.html` 测试不同的音效

## 故障排除

如果音效无法播放：
1. 检查浏览器是否支持 Web Audio API
2. 确认用户已与页面交互（点击过按钮）
3. 检查音频文件路径和格式
4. 查看浏览器控制台的错误信息

## 浏览器兼容性

支持的浏览器：
- Chrome 34+
- Firefox 25+
- Safari 6+
- Edge 12+

注意：某些浏览器要求用户交互后才能播放音频。
