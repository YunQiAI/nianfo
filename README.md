# 念佛计数器 Web 版

🙏 专注念佛 功德无量

## 功能特色

- 🥢 **木鱼模式**：按键敲击，真实木鱼音效
- ⏰ **节拍器模式**：自动念佛，可调节速度
- 🌟 **佛光普照**：禅修冥想，视觉特效
- 🌸 **莲花绽放**：专注模式下莲花随功德增长
- 🎋 **供奉贡品**：虚拟供奉水、花、灯、香

## 使用方法

1. 选择念佛模式：木鱼、节拍器或佛光普照
2. 开始念佛计数
3. 达到一定数量可进入专注模式
4. 供奉贡品积累功德

## 兼容性

- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 响应式设计，支持手机和平板
- 数据本地保存，无需联网

## 开发

这是一个纯前端应用，直接打开 `index.html` 即可使用。
